
TRAIN TICKET BOOKING APPLICATION
===============================

Project Name:
Train Ticket Booking Application using C

Description:
This project is used to reserve train tickets,
cancel tickets, view booking details, and display
train information.

Features:
1. Sign Up
2. Sign In
3. Password Validation
4. Display Train Details
5. Book Train Tickets
6. Cancel Tickets
7. View Booking Details
8. File Handling
9. Singly Linked List
10. Dynamic Memory Allocation

Technologies Used:
- C Programming
- Structures
- Pointers
- Singly Linked List
- Dynamic Memory Allocation
- File Handling
- Makefile

Files:
main.c
train.h
signup.c
signin.c
train.c
file.c
booking.c
cancel.c
booking_details.c
menu2.c
makefile
readme.txt

Data Files:
usr_logins
trains_info
passengers_info

Compilation:
Open the terminal in the project folder
and execute:

make

Execution:
./myirctc

Clean:
make clean

The application stores user details, train details,
and passenger booking information in files.
The old data is retained after restarting the program.
